Archives of Arcanum

Formerly Silverlight. The same workspace app, with a new name. Existing projects and community-license qualification continue unchanged.

A visual workspace for notes, references, and connected ideas. Build Boards, arrange Stickies, connect related thoughts, and organize projects with nested Boards.

View downloads ↗GitHub repository ↗

Your ideas, in context

Collect notes and images, import PDFs or supported reference exports, and explore relationships on a freeform canvas. Workspace data is saved locally on your device. Export independent backups to protect your work.

Optional Google Drive sync

Connect Google only if you want cloud copies or cross-device sync. Archives of Arcanum requests access to its own hidden Google Drive app-data folder using the drive.appdata permission. It uploads and reads workspace snapshots there; it does not request general access to your ordinary Drive files.

Enable live sync and join the same workspace on your devices using the same Google account. Sync checks for saved changes while apps are open and online. Pause live sync from the cloud menu. Pausing does not delete cloud copies or revoke Google access.

Download and installation

The Windows rename is targeted for version 0.13.5; the downloads page shows the latest successfully published build. Android downloads remain the legacy Silverlight 0.10.1 build while mobile development is paused.

  • Latest Windows release — select the Archives of Arcanum-Setup.exe asset.
  • Existing Android 0.10.1 APK — mobile development is paused; review the development focus and all releases.
  • Release notes — current changes and known limitations.

Back up your workspace before replacing or uninstalling a build. Android releases use a persistent signing identity; installations with a different historical signature may require uninstalling, which can erase local data. Check the notes for your chosen release.

A creator's passion project

Archives of Arcanum started because its creator was dissatisfied with their previous mind-map program. Code on main is largely AI-generated under human direction: the creator sets goals, makes decisions, and directs development. The work takes time and has costs; this process does not guarantee correctness or security.

An offline-first core

The full local core is intended to work offline. All sync, AI, and accounts are optional. The community license requires no telemetry or online license verification. Optional services, external content, and update checks can still make network requests; see the privacy policy. This documentation update changes no application behavior.
