Silverlight

A visual workspace for notes, references, and connected ideas. Build Boards, arrange Stickies, connect related thoughts, and organize projects with nested Boards.

View downloads ↗GitHub repository ↗

Your ideas, in context

Collect notes and images, import PDFs or supported reference exports, and explore relationships on a freeform canvas. Workspace data is saved locally on your device. Export independent backups to protect your work.

Optional Google Drive sync

Connect Google only if you want cloud copies or cross-device sync. Silverlight requests access to its own hidden Google Drive app-data folder using the drive.appdata permission. It uploads and reads workspace snapshots there; it does not request general access to your ordinary Drive files.

Enable live sync and join the same workspace on your devices using the same Google account. Sync checks for saved changes while apps are open and online. Pause live sync from the cloud menu. Pausing does not delete cloud copies or revoke Google access.

Read the full privacy policy for data categories, optional AI requests, credential storage, and deletion instructions.

Download and installation

  • Latest Android release — select the Silverlight.apk asset.
  • All releases and Windows packages — choose a release with Windows assets and review its installation notes.
  • Release notes — current changes and known limitations.

Back up your workspace before replacing or uninstalling a build. The repository documents Android test-signing limitations; mismatched signatures can require uninstalling, which can erase local data. Check the notes for your chosen release.

Support & project identity

Maintained by cosmerearchives-creator. The current source repository is named Mind-Map; its application is Silverlight. Report problems or privacy questions through GitHub Issues. Issues are public: do not include private board contents, credentials, or Google tokens.

Silverlight is an independent Cosmere Archives workspace app, not Microsoft Silverlight.
